🍎 NutriReceitas

Projeto de banco de dados relacional desenvolvido com MySQL para organizar receitas, ingredientes, usuários, dietas e avaliações.

🎯 Objetivo

Aplicar na prática conceitos de modelagem de dados e consultas SQL, desenvolvendo uma estrutura para relacionar e consultar informações sobre receitas e seus usuários.

🛠️ Tecnologias
MySQL
MySQL Workbench
SQL
📊 Consultas desenvolvidas
Busca de receitas por calorias e tempo de preparo.
Consulta de informações nutricionais.
Relacionamento entre usuários, receitas e avaliações.
Cálculo da média das avaliações.
Contagem de usuários por dieta.
🗂️ Estrutura do banco

O banco é composto por tabelas de receitas, ingredientes, usuários, dietas e avaliações, além de tabelas de relacionamento.

📚 Aprendizados

Prática de comandos SQL, relacionamentos entre tabelas com JOIN, filtros com WHERE, agrupamentos com GROUP BY, ordenação com ORDER BY e funções de agregação.
